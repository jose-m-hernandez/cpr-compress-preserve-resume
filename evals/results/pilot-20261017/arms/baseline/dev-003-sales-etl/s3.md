# sales-etl

A small script that loads a sales CSV and reports revenue per product.

## Overview

- Python 3, standard library only.
- Run it with `python3 -m etl data/sales_2025.csv`.
- Output is one tab-separated line per SKU.

## Layout

- `etl/load.py` reads the CSV into dictionaries.
- `etl/transform.py` computes revenue per SKU.
- `etl/report.py` writes totals to `out/report_<YYYY-MM>.txt` (`write_report`); not yet called from `__main__.py`.
- `etl/__main__.py` is the command-line entry point.
- `data/` holds input files.
- `out/` holds generated reports and is gitignored.
- `tests/` holds the unit tests.

## Decisions

| Decision | Reason |
|----------|--------|
| `unit_price` in the CSV is cents; `load.py` divides by 100 | Confirmed against the finance export |
| Revenue is `quantity * unit_price`, rounded to cents once, only when written | No per-row rounding |
| Negative-quantity rows are excluded with a stderr warning, not netted | Existing behavior; may differ from finance totals, so revisit for the comparison |

## Warnings

- Never edit `data/sales_2025.csv`; the nightly export overwrites it. Keep any finance export elsewhere.
- Prices are binary floats; switch to `decimal.Decimal` if exact cents matter.
