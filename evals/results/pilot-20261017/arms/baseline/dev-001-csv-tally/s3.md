# tally

A small command-line tool that sums and counts columns in CSV files.

## Overview

- Python 3, standard library only.
- Run it with `python3 -m tally FILE --column NAME`.
- It prints one number to standard output.

## Layout

- `tally/core.py` loads rows (`load_rows`), sums a column and counts rows.
- `tally/cli.py` parses arguments and prints the result.
- `tests/` holds the unit tests.
- `samples/` holds small example input files:
  - `basic.csv`: comma-separated, sums to 10.
  - `semicolons.csv`: semicolon-separated, used by the delimiter and `--count` tests.
  - `eu.csv`: semicolons and decimal commas; it fails on purpose (see Status).

## Commands

- Run the tests: `python3 -m unittest discover tests`.
- Try it: `python3 -m tally samples/basic.csv --column amount`.

## Conventions

- Four-space indentation and type hints on public functions.
- Keep functions short and give each one a test.
- No third-party dependencies.
- Error messages name the column and the row number.
- New tests read their input from files in `samples/`, not inline strings.

## Status

- Done and tested: `--delimiter` (default `,`) and `--count` (`--column` is optional only with `--count`).
- `read_rows` was renamed to `load_rows`.
- Not started: exit codes, `--output json`, README docs.
- Known and left alone: `samples/eu.csv` raises a raw `ValueError` traceback because `parse_number` rejects decimal commas.
- Cleanup: `samples/semicolon.csv` is a stale duplicate of `semicolons.csv`; delete it.

## Decisions

| Decision | Reason |
| --- | --- |
| The user passes `--delimiter`; no sniffing | Sniffing misreads quoted fields |
| Exit 2 for usage errors, 3 for data errors such as a bad number | Matches argparse for usage errors; data errors need their own code |
| No `--jobs` / multiprocessing | A scratch-branch attempt was slower on small files and was reverted |
