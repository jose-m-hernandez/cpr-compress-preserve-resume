# tally

A small command-line tool that sums and counts columns in CSV files.

## Overview

- Python 3, standard library only.
- Run it with `python3 -m tally FILE --column NAME`.
- It prints one number to standard output.
- `--delimiter CHAR` (default `,`) sets the field separator; `--count` prints the data-row count instead of the sum and makes `--column` optional.
- The release branch will be called BLUEFINCH (not created yet).

## Layout

- `tally/core.py` loads rows (`load_rows`), sums a column and counts rows.
- `tally/cli.py` parses arguments and prints the result.
- `tests/` holds the unit tests.
- `samples/` holds small example input files (`basic.csv`, `semicolons.csv`, `eu.csv`).

## Commands

- Run the tests: `python3 -m unittest discover tests`.
- Try it: `python3 -m tally samples/basic.csv --column amount`.

## Conventions

- Four-space indentation and type hints on public functions.
- Keep functions short and give each one a test.
- No third-party dependencies.
- Error messages name the column and the row number.
- New tests read their input from files in `samples/`, not inline strings.

## Decisions

| Decision | Reason |
|---|---|
| The user passes `--delimiter` explicitly; no sniffing | Sniffing misreads quoted fields |
| Decimals must use `.`; `samples/eu.csv` (`;` and `1,5`) deliberately fails | Decimal-comma support is a separate feature, not part of `--delimiter` |
| No `--jobs` / multiprocessing | Tried and reverted: slower on small files |
| Exit codes: usage errors 2 (argparse), data errors such as a bad number 3 | Chosen by the user; not implemented yet |
