# tally

A small command-line tool that sums and counts columns in CSV files.

## Overview

- Python 3, standard library only.
- Run it with `python3 -m tally FILE --column NAME`.
- It prints one number to standard output.

## Layout

- `tally/core.py` reads rows and sums a column.
- `tally/cli.py` parses arguments and prints the result.
- `tests/` holds the unit tests.
- `samples/` holds small example input files.

## Commands

- Run the tests: `python3 -m unittest discover tests`.
- Try it: `python3 -m tally samples/basic.csv --column amount`.

## Conventions

- Four-space indentation and type hints on public functions.
- Keep functions short and give each one a test.
- No third-party dependencies.
- Error messages name the column and the row number.
- New tests read their input from files in `samples/`, not inline strings.

## Status

- Done and tested: `--delimiter` (default `,`) and `--count` (prints the data-row count; `--column` is only required without it).
- `core.read_rows` was renamed to `core.load_rows`.
- Not started: exit codes, `--output json`, README docs.
- Uncommitted: all of the above is in the working tree on `main`.

## Decisions

| Decision | Reason |
| --- | --- |
| `--delimiter` is user-supplied, never sniffed | Sniffing misreads quoted fields |
| Exit codes: usage errors 2 (argparse style), data errors such as a bad number 3 | User's plan; not wired up yet |
| No `--jobs` / multiprocessing | Tried and reverted: slower on small files |
| Release branch will be named `BLUEFINCH` | From the team standup notes; the branch does not exist yet |

## Warnings

- `samples/eu.csv` uses `;` and decimal commas, so it fails with a bad-number `ValueError` (raw traceback) even with `--delimiter ';'`. Left alone on purpose.
- `samples/semicolon.csv` is a stray duplicate of `samples/semicolons.csv`; delete it.
