# cronish

A small library that parses cron-like schedule expressions.

## Overview

- Python 3, standard library only.
- Inspect an expression with `python3 -m cronish 'MINUTE HOUR WEEKDAY'`.

## Layout

- `cronish/parser.py` parses an expression into a schedule.
- `cronish/errors.py` defines `ExprError`, a `ValueError` subclass.
- `cronish/nextrun.py` has `next_run(schedule, after)`, the next matching minute.
- `cronish/__main__.py` prints the parsed fields.
- `tests/` holds the unit tests.

## Status

- Work is not committed yet. The release branch is `HALCYONMOTH`; work is currently on `main`.

## Decisions

| Decision | Reason |
|---|---|
| Three fields only: minute, hour, weekday; no seconds or month | The scheduler wakes once a minute. |
| Every parse failure raises `ExprError` with the field name in the message | Callers and the CLI catch one type; it still subclasses `ValueError`. |
| Weekdays are numbers only (Sunday is 0, 7 is rejected); no names like `MON` | Names were added, then removed as a locale headache. Do not re-add. |
| No third-party scheduler package | The one considered had a licence problem. |
