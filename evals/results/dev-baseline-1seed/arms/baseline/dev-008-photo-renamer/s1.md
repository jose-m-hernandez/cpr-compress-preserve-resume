# renamer

Renames photo files using a text sidecar that lists a date and a title for each file.

## Overview

- Python 3, standard library only.
- Preview with `python3 -m renamer plan DIR`; DIR must contain an `index.txt` sidecar.
- Rename for real with `python3 -m renamer apply DIR --yes`. Without `--yes` it exits 2 and changes nothing.

## Status

- `plan`, `apply` and the slug rules are done and tested (15 tests pass).
- `apply` writes the undo log, but the `undo` command that reads it is not written yet.
- All of this work is uncommitted on `main`. The release branch is `FERNGULLY`; nothing has been created or committed on it.

## Layout

- `renamer/sidecar.py` reads the sidecar into records.
- `renamer/plan.py` turns records into old and new names, and `apply_plan` does the renames.
- `renamer/undo.py` reads and writes the undo log, `.renamer-undo.json` in DIR.
- `renamer/cli.py` parses arguments and runs `plan` and `apply`.
- `samples/` holds small example folders. `samples/dup` is meant to fail the duplicate-target check.
- `tests/` holds the unit tests.

## Commands

- Run the tests: `python3 -m unittest discover tests`.
- Try it: `python3 -m renamer plan samples/basic`.
- Do not run `apply` on `samples/`; it renames the sample files.

## Decisions

| Decision | Reason |
|----------|--------|
| `apply` needs `--yes` | A rename can't be undone by hand once the originals are gone. |
| `apply_plan` checks every source and target before renaming anything | A bad plan must not leave the folder half-renamed. |
| Slug is lowercase, runs of non-`a-z0-9` become one hyphen, capped at 30 (`SLUG_MAX`) | The NAS file manager truncates longer names. |
| Undo log is written after the checks and before the first rename, and later applies append | Earlier applies stay reversible. |
| Plan is sorted by old name | Sorting by date was tried and gave the same output, so it was reverted. |

## Open questions

- The 30-character cap covers only the slug. A full name can reach 44 characters (date, underscore, slug, 3-letter extension). If the NAS limit is on the whole filename, the cap must be lowered or applied to the whole name.
- Non-ASCII letters in titles are dropped, so `café` becomes `caf`. Transliterating is undecided.

## Conventions

- Four-space indentation and docstrings on public functions.
- Keep functions short and give each one a test.
- No third-party dependencies.
- In the sandbox, one Bash command per call. Compound commands and brace-with-quote patterns in shell scripts are blocked, so use the file tools for multi-file edits.
