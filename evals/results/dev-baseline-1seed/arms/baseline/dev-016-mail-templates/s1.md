# mailtpl

A small library that fills in and checks plain-text message templates.

## Overview

- Python 3, standard library only.
- Check a template with `python3 -m mailtpl check FILE`.

## Layout

- `mailtpl/render.py` fills a template with values, raises `MissingValue`, and appends the footer.
- `mailtpl/check.py` checks a template for problems (unknown placeholders, subject over 60 characters).
- `mailtpl/footer.py` holds the footer text (`FOOTER`) and `add_footer`.
- `mailtpl/__main__.py` is the command-line entry point.
- `templates/` holds the message templates.
- `tests/` holds the unit tests.

## Commands

- Run the tests: `python3 -m unittest discover tests`.
- Try it: `python3 -m mailtpl check templates/reminder.txt`.

## Conventions

- Four-space indentation and docstrings on public functions.
- Keep functions short and give each one a test.
- No third-party dependencies. A templating library was tried and dropped as overkill, and it slipped the newsletter launch a week.

## Decisions

- `render` raises `MissingValue` for a missing, `None`, empty or whitespace-only value, because a blank greeting went out last year. Real falsy values such as `0` are kept.
- Subject limit is 60 characters (`MAX_SUBJECT` in `mailtpl/check.py`), because phones cut longer ones off. Placeholders count as literal text.
- Footer is "Use the link to unsubscribe", because the mail rules require a link, not a reply keyword. It is text only and adds no URL.
