# rota

A command-line tool that builds a weekly staff rota from each person's available days.

## Overview

- Python 3, standard library only.
- Run it with `python3 -m rota AVAILABILITY_FILE`.

## Layout

- `rota/availability.py` reads the availability file.
- `rota/planner.py` assigns people to days (`PER_DAY`, `MAX_SHIFTS`, `assign`, `pick_for_day`, `can_work`).
- `rota/export.py` writes the rota as CSV for the front desk (`write_csv`, `rota_to_csv`). Not yet wired into the command line.
- `rota/__main__.py` prints the rota.
- `data/` holds example availability files.
- `tests/` holds the unit tests.

## Commands

- Run the tests: `python3 -m unittest discover tests`.
- Try it: `python3 -m rota data/avail.txt`.

## Status

- Done and tested: deterministic planner, 3 people per day, 3-shift weekly cap, CSV export (23 tests passing).
- Changes are uncommitted on `main`. The release branch is called `COBBLEFERRY`; nothing has been put on it yet.

## Decisions

| Decision | Reason |
|---|---|
| Round-robin in name order, never random | People check the rota by hand. |
| Each day carries on from the person after the last one picked | Spreads shifts evenly. |
| At most 3 shifts per person per week (`MAX_SHIFTS`) | Staff contract limit. |
| 3 people per day (`PER_DAY`) | The weekend is busier than expected. |
| A day may be short-staffed when everyone available is capped | No error or warning is raised. |

## Warnings

- Fully staffing a week at 3 per day needs 21 shifts, so at least 7 people. `data/avail.txt` has 4, so most days are short.
