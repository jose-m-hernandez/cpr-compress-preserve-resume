# shortener

A tiny link shortener that keeps its links in memory.

## Overview

- Python 3, standard library only.
- Run the URL check with `python3 -m shortener check URL`.
- Release branch: `COPPERLARK`. The demo moved to the 14th.

## Status

- Done and tested: `POST /shorten`, `GET /<code>` redirect (302), link expiry.
- Not started: hit counters.

## Layout

- `shortener/store.py` holds the in-memory store.
- `shortener/urls.py` checks a URL before it is stored.
- `shortener/routes.py` holds `handle(method, path, body, store)`, which returns `(status, headers, body)`.
- `tests/` holds the unit tests.

## Decisions

| Decision | Reason |
| --- | --- |
| Codes are 6 base-36 characters counted up from `000000`, no randomness | Tests must be deterministic. A benchmark found random vs counter codes was noise. |
| Links expire after 7 days (`TTL_SECONDS` in `store.py`) | Links go out in a weekly newsletter. |
| `Store(clock=time.time)` takes a clock function | Tests move time with a fake clock instead of sleeping. |
| `POST /shorten` answers 201 with the code as the body | Spec did not say; easy to change. |

## Warnings

- Test `handle()` by calling it directly, never by binding a socket: the CI sandbox refuses ports.
- Sequential codes are guessable, so links are not private.

## Commands

- Run the tests: `python3 -m unittest discover tests`.
- Check a URL: `python3 -m shortener check https://example.com/a`.

## Conventions

- Four-space indentation and docstrings on public functions.
- Keep functions short and give each one a test.
- No third-party dependencies.
