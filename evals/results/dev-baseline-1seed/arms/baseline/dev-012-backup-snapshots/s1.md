# snap

A command-line tool that copies a directory into dated snapshots and prunes old ones.

## Overview

- Python 3, standard library only.
- Run it with `python3 -m snap snapshot SRC DEST` or `python3 -m snap prune DEST [--keep N]` (default keep is 10).
- The release branch is called MOONSALT.

## Decisions

- Snapshot folders are named with a UTC timestamp like `20260502T101500`, so an alphabetical sort is chronological.
- Prune deletes only folders matching `[0-9]{8}T[0-9]{6}`, because the destination also holds other people's files. Stray folders and files are never touched and don't count toward `--keep`.
- Default keep is 10, not 7: seven was too few for the nightly runs.
- Tests pass timestamps in rather than sleeping to get distinct ones, to keep the suite fast.

## Warnings

- Snapshots made with the old `YYYYMMDD-HHMMSS` names are treated as strays by prune and must be cleared by hand.
- A source file named `MANIFEST.json` at the top of the source tree is overwritten in the snapshot by the generated manifest.
- Our tool is slower than rsync on big trees. Accepted for now.

## Layout

- `snap/snapshot.py` copies a directory into a new snapshot folder named by `make_stamp()`.
- `snap/manifest.py` writes `MANIFEST.json` (file paths and sizes) into each snapshot.
- `snap/prune.py` removes the oldest snapshots.
- `snap/cli.py` parses arguments and runs the commands.
- `samples/` holds a small example tree.
- `tests/` holds the unit tests.

## Commands

- Run the tests: `python3 -m unittest discover tests`.
- Try it: `python3 -m snap snapshot samples/tree out`.

## Conventions

- Four-space indentation and docstrings on public functions.
- Keep functions short and give each one a test.
- No third-party dependencies.
