# tally

A small command-line tool that sums and counts columns in CSV files.

## Overview

- Python 3, standard library only.
- Run it with `python3 -m tally FILE --column NAME`.
- It prints one number to standard output.
- Options: `--delimiter` (default `,`), `--count` (prints the row count instead of the sum; `--column` is then optional).

## Status

- Done and tested: `--delimiter`, `--count`.
- Not started: exit codes, `--output json`, README docs.

## Layout

- `tally/core.py` loads rows (`load_rows`, formerly `read_rows`), sums a column and counts rows.
- `tally/cli.py` parses arguments and prints the result.
- `tests/` holds the unit tests.
- `samples/` holds small example input files: `basic.csv`, `semicolons.csv` (`;`-separated), `eu.csv` (`;`-separated with decimal commas).

## Commands

- Run the tests: `python3 -m unittest discover tests`.
- Try it: `python3 -m tally samples/basic.csv --column amount`.

## Conventions

- Four-space indentation and type hints on public functions.
- Keep functions short and give each one a test.
- No third-party dependencies.
- Error messages name the column and the row number.
- New tests read their input from files in `samples/`, not inline strings.

## Decisions

| Decision | Reason |
| --- | --- |
| The user passes `--delimiter`; never sniff it | Sniffing misreads quoted fields |
| Exit codes: usage errors 2 (as argparse), data errors such as a bad number 3 | The user's plan; not implemented yet |
| No `--jobs` / multiprocessing | Tried on a scratch branch and reverted: slower on small files |

## Warnings

- `samples/eu.csv` fails by design: `parse_number` accepts only `.` decimals, and a bad number still ends in a raw `ValueError` traceback.
- `samples/semicolon.csv` is a leftover duplicate of `samples/semicolons.csv`; delete it.
