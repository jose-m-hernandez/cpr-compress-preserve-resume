# cronish

A small library that parses cron-like schedule expressions.

## Overview

- Python 3, standard library only.
- Inspect an expression with `python3 -m cronish 'MINUTE HOUR WEEKDAY'`.

## Layout

- `cronish/parser.py` parses an expression into a schedule.
- `cronish/__main__.py` prints the parsed fields.
- `tests/` holds the unit tests.

## Commands

- Run the tests: `python3 -m unittest discover tests`.
- Try it: `python3 -m cronish '*/15 9-17 1-5'`.

## Conventions

- Four-space indentation and docstrings on public functions.
- Keep functions short and give each one a test.
- No third-party dependencies.

## Decisions
- Expressions are `minute hour weekday` only (no seconds, no month): the scheduler wakes once a minute.
- Weekdays are numbers only; names (MON-FRI) were removed because of locale trouble.

## Structure
- `cronish/nextrun.py` holds `next_run(schedule, after)`.

## Patterns
- Parse failures raise `ExprError` (a `ValueError` subclass, `cronish/errors.py`) naming the field.

## Warnings
- Weekday 7 is rejected; Sunday is 0.

## Status
- Done: parsing, `next_run`, `ExprError`. Not started: the `--next` flag.
