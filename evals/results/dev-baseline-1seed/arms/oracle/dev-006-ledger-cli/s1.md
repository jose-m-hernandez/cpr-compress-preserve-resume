# ledger

A small command-line tool that summarises a plain-text expense ledger.

## Overview

- Python 3, standard library only.
- Run it with `python3 -m ledger FILE`.
- It prints one line per category with the total spent.

## Layout

- `ledger/parse.py` turns ledger lines into entries.
- `ledger/summary.py` totals the entries and formats the report.
- `ledger/cli.py` parses arguments and prints the result.
- `data/` holds small example ledger files.
- `tests/` holds the unit tests.

## Ledger format

- One entry per line: `DATE | DESCRIPTION | AMOUNT | CATEGORY`.
- Blank lines and lines starting with `#` are ignored.

## Commands

- Run the tests: `python3 -m unittest discover tests`.
- Try it: `python3 -m ledger data/sample.txt`.

## Conventions

- Four-space indentation and docstrings on public functions.
- Keep functions short and give each one a test.
- Errors are reported as `error: line N: ...` on standard error.

## Decisions
- Amounts are integer cents internally, never floats: float sums drifted by a cent against a spreadsheet.
- Default grouping is by month (`--by`), changed from week.
- `--top` defaults to 3, not 5, because the report was too long.
- No file argument: use the `LEDGER_FILE` environment variable, else `data/ledger.txt`.

## Structure
- `ledger/money.py`: cents conversion helpers.
- `ledger/report.py` formats the report; `ledger/summary.py` only totals.

## Warnings
- Negative amounts are rejected; enter a refund as a positive amount under category `refund`.
- Blocked: budget limits wait for the accountant's category list; categories stay free text.

## Patterns
- Option tests call `main(argv)` directly, not a subprocess (slow in CI).
- Categories are stored lowercase; `Food` and `food` are one bucket.
