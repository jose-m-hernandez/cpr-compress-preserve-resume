# snap

A command-line tool that copies a directory into dated snapshots and prunes old ones.

## Overview

- Python 3, standard library only.
- Run it with `python3 -m snap snapshot SRC DEST` or `python3 -m snap prune DEST --keep N`.

## Layout

- `snap/snapshot.py` copies a directory into a new snapshot folder.
- `snap/prune.py` removes the oldest snapshots.
- `snap/cli.py` parses arguments and runs the commands.
- `samples/` holds a small example tree.
- `tests/` holds the unit tests.

## Commands

- Run the tests: `python3 -m unittest discover tests`.
- Try it: `python3 -m snap snapshot samples/tree out`.

## Conventions

- Four-space indentation and docstrings on public functions.
- Keep functions short and give each one a test.
- No third-party dependencies.

## Decisions
- Snapshot folders are named by UTC timestamp (`20260502T101500`), so name order is time order.
- `prune` keeps the newest 10 by default (was 7): 7 was too few for nightly runs.
- `prune` only deletes timestamp-named folders: the destination also holds other people's files.

## Structure
- `snap/manifest.py` writes `MANIFEST.json` (paths and sizes) into each snapshot.

## Patterns
- Tests pass the timestamp in; never sleep for distinct ones (slow suite).

## Warnings
- A destination inside the source is refused (the snapshot would copy itself).

## Status
- Done: snapshot, manifest, prune. Not started: restore.
