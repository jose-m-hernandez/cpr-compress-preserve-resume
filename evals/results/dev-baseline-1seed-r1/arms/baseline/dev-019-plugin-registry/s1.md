# plugins

A small library for registering plugins by name and looking them up later.

## Overview

- Python 3, standard library only.
- Check a list of plugin names with `python3 -m plugins check FILE`.

## Layout

- `plugins/registry.py` holds the registry and `PluginNotFound`.
- `plugins/hooks.py` holds `HOOKS`, the only hook points plugins may attach to.
- `plugins/__main__.py` is the command-line entry point.
- `data/` holds example name lists.
- `tests/` holds the unit tests.

## Status

- The release branch is `SPINDLEWREN`. Work so far is uncommitted on `main`.

## Decisions

| Decision | Reason |
| --- | --- |
| Plugin names are lowercase kebab-case, such as `csv-export` | They appear in config files and URLs |
| `get()` raises `PluginNotFound` (a `KeyError` subclass), never returns `None` | A silent `None` hid a config typo for a week |
| Factories take no arguments; settings arrive through `configure(settings)` afterwards | Set by the user; the registry does not call `configure` |
| Hook points are `before_run` and `after_run` only | Set by the user |
| No entry-point plugin loading | Tried and dropped as overkill |

- Four-space indentation and docstrings on public functions.
- Keep functions short and give each one a test.
- No third-party dependencies.
