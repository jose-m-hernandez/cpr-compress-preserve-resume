# ledger

A small command-line tool that summarises a plain-text expense ledger.

## Overview

- Python 3, standard library only.
- Run it with `python3 -m ledger [FILE]`. FILE falls back to `$LEDGER_FILE`, then `data/ledger.txt` (not in the repo).
- It prints one line per group with the total spent. Options: `--by {category,week,month}` (default `month`, labelled `YYYY-MM`; weeks by their Monday), `--top N` (default 3), `--since YYYY-MM-DD` (inclusive).

## Layout

- `ledger/parse.py` turns ledger lines into entries.
- `ledger/money.py` converts between dollar text and integer cents.
- `ledger/summary.py` filters and totals the entries (grouping, `--top`, `--since`).
- `ledger/report.py` formats the printed report.
- `ledger/cli.py` parses arguments and prints the result.
- `data/` holds small example ledger files.
- `tests/` holds the unit tests.

## Ledger format

- One entry per line: `DATE | DESCRIPTION | AMOUNT | CATEGORY`.
- Blank lines and lines starting with `#` are ignored.
- DATE must be `YYYY-MM-DD`. AMOUNT is positive with at most two decimals; refunds use category `refund`, never a negative amount.
- Categories are free text and stored lowercase. Do not validate against a fixed list until the accountant sends one (expected after the audit).

## Decisions

| Decision | Reason |
|---|---|
| Amounts are integer cents, no floats anywhere in sums | Float totals drifted a cent against the user's spreadsheet |
| More than two decimals is an error, not rounded | Avoid silent rounding |
| Default grouping is `month` | Review moved from Mondays to month end |
| `--top` defaults to 3 | The report was too long for the user's terminal |

## Commands

- Run the tests: `python3 -m unittest discover tests`.
- Try it: `python3 -m ledger data/sample.txt`.

## Conventions

- Four-space indentation and docstrings on public functions.
- Keep functions short and give each one a test.
- Errors are reported as `error: line N: ...` on standard error.
- Option tests call `main(argv)` directly, never a subprocess (slow subprocess runs held up the user's CI elsewhere).
- No ANSI colour in output; it garbled piped output and was reverted.
