# cisum

A script that summarises a folder of CI job result files.

## Overview

- Python 3, standard library only.
- Run it with `python3 -m cisum RESULTS_DIR`.

## Layout

- `cisum/parse.py` reads the result files.
- `cisum/summary.py` counts outcomes, adds up time, merges jobs by name and finds slow jobs.
- `cisum/markdown.py` renders the summary as a markdown table for the pull-request comment.
- `cisum/__main__.py` prints the summary.
- `samples/` holds example result folders. `samples/odd` has a `skipped` job and is rejected on purpose.
- `tests/` holds the unit tests. `tests/test_main.py` runs the command in a subprocess.

## Status

- Done and tested: parsing, slow-job list, flaky handling, markdown renderer, case-insensitive job names.
- `render_markdown` is not wired to the command line yet (no `--markdown` flag).
- Slow-job printing in `__main__.py` has no test.

## Decisions

| Decision | Reason |
| --- | --- |
| A job is slow above 120 seconds (`SLOW_SECONDS` in `cisum/summary.py`) | The integration suite legitimately takes about 90 |
| Flaky jobs are reported but never change the exit code; only `failed` exits 1 | Flaky tests are being fixed and the build must stay green meanwhile |
| Job names match case-insensitively; the later entry (sorted by file name) wins | The CI provider renamed `Unit` to `unit`, so one job showed up twice |
| Release branch is `OTTERSPIRE` | Stated by the user |
