# inventory

Compares two JSON stock lists and reports what changed between them.

## Overview

- Python 3, standard library only.
- Run it with `python3 -m inventory [--json] OLD.json NEW.json`.
- The release branch is `LANTERNFISH`. Work so far is uncommitted on `main`.

## Status

- Done and tested: loader, diff, tolerance, `--json`.
- Not started: CSV import.

## Decisions

| Decision | Reason |
| --- | --- |
| `SCALE_TOLERANCE = 1` in `cli.py`; `compare(..., tolerance=0)` defaults to exact | The counting scale reads to the unit (was 2 on the old scale). Added and removed SKUs are never hidden. |
| The plain table (`render_table`) goes away after the next release | Don't polish it. `--json` is the lasting format. |
| Tests build inventories in code via `tests/helpers.py`, never from `data/` | The data files drifted from the code last time. |

## Layout

- `inventory/loader.py` reads and validates a stock list.
- `inventory/diff.py` compares two stock lists.
- `inventory/render.py` formats differences: `render_table` and `render_json` (one JSON object per line).
- `inventory/cli.py` parses arguments and prints the rendered differences.
- `data/` holds small example stock lists, for trying the CLI only.
- `tests/` holds the unit tests; `tests/helpers.py` has the shared setup (`write_stock`, `sample_differences`).

## Warnings

- Tests import `from helpers import ...`, which only works under `python3 -m unittest discover tests`, not `python3 -m unittest tests.test_x`.
- `--json` is found with a plain `in` check on the arguments. Switch to argparse when a second flag arrives.
- No test checks that the CLI passes `SCALE_TOLERANCE` to `compare`, or runs `main` with `--json`.

## Commands

- Run the tests: `python3 -m unittest discover tests`.
- Try it: `python3 -m inventory data/old.json data/new.json`.

## Conventions

- Four-space indentation and docstrings on public functions.
- Keep functions short and give each one a test.
- No third-party dependencies.
